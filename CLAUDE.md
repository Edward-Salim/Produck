# Produck

## Style rules

- Never use em dashes. Use commas, colons, semicolons, or periods instead.
- Write instructions and copy in plain, conversational language. Avoid technical jargon in user-facing text (stories, labels, help panels).

## Claude Code Rules

- **Avoid hitting output token limits:** Always write code directly to files using the `Edit` or `Write` tools instead of printing code blocks in the chat.
- **Be concise:** Keep conversational output and explanations extremely concise. Do not explain the code unless explicitly asked to do so; just apply the changes.
